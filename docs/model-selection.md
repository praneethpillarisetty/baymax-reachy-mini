# Model selection (provisional)

No onboard model is recommended yet: listing metadata is not proof of Raspberry Pi execution. Benchmark exact LiteRT artifacts for MiniCPM5-1B, a compact Gemma 1B/Gemma 3n variant, Granite 350M, and the newest official compact text-generation entry after verifying runtime format, supported CPU/accelerator architecture, tokenizer, conversion provenance, RAM/disk needs, context, and license. Granite 350M may minimize pressure while ~1B models may improve responses, but these are hypotheses, not rankings or compatibility claims.

Qwen 3 4B via Ollama is the configurable laptop baseline. MedGemma 4B is an optional laptop research model only and must not be treated as an onboard default or a source of medical authority.

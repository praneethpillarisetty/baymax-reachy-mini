# Healthcare safety

This wellness companion is not a medical device, doctor, emergency dispatcher, or substitute for professional care. A deterministic pre-model matcher handles breathing difficulty, chest pain, common stroke wording, severe bleeding, overdose, unconsciousness, severe allergy, and suicide/self-harm wording with an immediate emergency-services response. Matching is necessarily incomplete; uncertain or urgent situations require local emergency services.

The model must not diagnose, prescribe, alter dosage, assert symptom certainty, fabricate records/appointments/reminders, or report unconfirmed tool success. Safety is enforced in code and not only through a prompt. Expand and clinically review patterns before any real-world study.

# Simulator

The built-in hardware-independent simulator runs with `BAYMAX_MODE=simulator baymax --once "hello"` or `python scripts/simulator_demo.py --once "hello"`. It records only allow-listed choreography names, honors cancellation, and performs safe shutdown. This is the CI simulator, not a claim that the official Reachy 3-D simulator was launched.

The exact current official Reachy Mini simulator installation and launch commands remain gated on retrieving the requested Hugging Face page. Do not substitute Reachy 2 commands.
